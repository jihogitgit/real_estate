### 2. `scripts/fetch-kapt-codes.mjs` — kapt_code 매핑

공공데이터포털 `AptListService3/getTotalAptList3` API로 전국 K-APT 단지 목록(22,207건)을 다운로드하고, `properties` 테이블과 이름 + 시군구코드(5자리) 기준으로 매핑한다.

**핵심 로직:**
- Supabase 기본 1,000행 limit → `.range()` 페이지네이션으로 전체 81,300건 조회
- 이름 정규화: 공백·특수문자 제거, "단지" 접미사 제거, 소문자, 부분 포함 일치
- 후보 2개 이상이면 완전 일치 우선, 없으면 건너뜀(ambiguous)
- kapt_code별로 `.in('id', ids)` 배치 업데이트

**실행 결과:**
- DB 단지 조회: 81,300건
- 매칭 완료: 5,564건 / 미매칭: 74,768건 / 모호: 968건
- 누적 kapt_code 보유: **6,061건**

**실행 명령:**
```bash
env $(cat .env.local | grep -v '^#' | xargs) ~/.nvm/versions/node/v22.22.3/bin/node scripts/fetch-kapt-codes.mjs
```

### 3. `scripts/fetch-apt-units.mjs` — 세대수 수집

공공데이터포털 `AptBasisInfoServiceV4/getAphusBassInfoV4` API로 kapt_code별 세대수(`hoCnt`)를 수집해 `properties.total_units`에 저장한다.

**주의사항:**
- 엔드포인트: `getAphusBassInfoV4` (세대수 있음) — `getAphusDtlInfoV4`는 관리 정보만 있어서 세대수 없음
- 세대수 필드: `hoCnt` (쉼표 포함 문자열일 수 있어서 replace 처리)
- Supabase 1,000행 limit → `.range()` 페이지네이션 필수

**실행 결과:**
- 대상: 5,517건 (kapt_code 있고 total_units null)
- 성공(OK): **5,458건**
- 데이터 없음(SKIP): 59건
- 오류(ERR): 2건
- 누적 total_units 보유: **6,002건**

**실행 명령:**
```bash
env $(cat .env.local | grep -v '^#' | xargs) ~/.nvm/versions/node/v22.22.3/bin/node scripts/fetch-apt-units.mjs
```

## 트러블슈팅

### Node.js v18 WebSocket 오류
`@supabase/realtime-js`가 Node.js 18에서 native WebSocket 미지원으로 crash 발생.
→ **해결:** `~/.nvm/versions/node/v22.22.3/bin/node` 직접 지정

### V4 API 403 오류
공공데이터포털에서 신규 API 키 발급 후 활용신청 승인이 실시간 반영 안 됨.
→ **해결:** 승인 후 30분~2시간 대기 필요. 자동 해소됨.

### Supabase 1,000행 기본 limit
`.select()` 결과가 1,000건에서 잘림 — 별도 에러 없이 조용히 잘려서 발견이 늦었음.
→ **해결:** 모든 전체 조회에 `.range(from, from + PAGE - 1)` 루프 필수

### getAphusDtlInfoV4 세대수 없음
`getAphusDtlInfoV4`를 사용하면 응답에 `kaptFacelt` 필드가 없어 세대수를 얻을 수 없음.
→ **해결:** `getAphusBassInfoV4` 엔드포인트의 `hoCnt` 필드 사용
